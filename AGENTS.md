# CodeHead: project instructions

- Общение и документация для автора — на русском; код, комментарии, имена файлов — на английском.
- Единственный нормативный источник требований — `docs/TECHNICAL_SPEC.md` (R/A/V). `README.md` описывает фактический запуск, `docs/IMPLEMENTATION_PLAN.md` — текущий этап, `docs/CHANGELOG.md` — историю решений.
- Платформа использует PostgreSQL. SQLite разрешена только будущему генерируемому Clinic Demo.
- Python владеет контрактами. После изменения `contracts.py` обновляй `packages/contracts` через генератор.
- Событие и изменение состояния фиксируются одной транзакцией. `seq` выделяется под блокировкой строки Run.
- Длительные LLM/Runner-операции выполняются worker, никогда внутри HTTP или BackgroundTasks.
- Не подменяй live симуляцией. Недоступные возможности явно обозначаются; неизвестные расходы не равны нулю.
- Проверки БД запускаются только в отдельной тестовой базе. Не удаляй данные `.data/postgres`.
- Секреты только через окружение. Не читай и не копируй ключи из чужих конфигураций.
- Windows, PowerShell 5.1: без `&&`, пути с пробелами в кавычках, exe через `&`.
- Перед отчётом запускай проверки и показывай фактический вывод. Коммиты и push только по просьбе пользователя.

Глобальные git config не менять, hooks не пропускать, force/reset --hard и удаление истории не выполнять без отдельной просьбы.
