## Интерфейс

Во вкладке «Preview» доступны ZIP, отчёты, «Запустить preview», «Открыть» и «Остановить preview». Адрес выдаётся для сессии `ready` при свежем health и действующем lease. При потере worker неизвестный исход сохраняется в истории. Проекция использует сохранённые переходы сессии, а текущую доступность получает отдельным запросом.

Playwright проверил скачанный SHA-256, явное открытие, изоляцию iframe от CodeHead, создание врача и пациентов, запись на приём и `409` для занятого слота. После reload вкладка сохранила сессию без автоматического открытия. После остановки и нового запуска SQLite сохранила данные. Клавиатурное управление прошло при 430 px без WebGL. ## Проверки

```text
npm run test:backend                     658 passed in 718.58s
npm run check                            417 tests, Ruff, TypeScript, contracts in sync
npm run build                            built in 1.42s
npm run test:e2e                         23 passed, 13 skipped (режим без worker)
npm run test:e2e -- --with-worker tests/e2e/preview.spec.ts   1 passed (2.3m)
```

Все 13 сценариев, требующих worker, прошли в прогоне `--with-worker`, включая два предыдущих QA-сценария, Runner и Run controls. В том же прогоне четыре старых сценария ожидали остановленной очереди. Запуск без worker подтвердил их штатный режим. [Без worker](../.data/reports/e2e-1795715743321/html/index.html) · [С worker](../.data/reports/e2e-1795714176923/html/index.html)

В итоговом ревью воспроизведено совпадение пользовательского Stop с завершением health-check. Сессия теперь принимает подтверждённую остановку от своего runtime даже после снятия процессов с учёта. PostgreSQL-снимки и журнал используют UTC, а проекция принимает равные моменты времени с разными смещениями и сохраняет микросекунды.

Vite предупреждает о размере существующего чанка 3D-рендера и Vitest выводит предупреждения Three.js. Повтор `npm run check` после завершения браузерного прогона прошёл с настройками репозитория.

## Локальный запуск

Миграция `0008_delivery` применена. API `/health` вернул `status=ok`, `database=ready`, `stage=worker`; UI вернул HTTP 200. Два ранее сохранённых запуска остались в базе. Интеграционные проверки использовали `codehead_test` и отдельные схемы.

Доставка относится к учебному профилю и тестовому провайдеру. `process_only` ограничивает запуск и владение процессами. Изоляция пользовательских файлов и сети требует отдельного Runner. Live и пользовательский replay входят в следующие этапы.
