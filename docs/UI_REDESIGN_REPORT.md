# CodeHead — визуальная переработка foundation

22 ноября 2026 года. Продолжение незавершённого запроса о размере карты, подписях, палитре и эргономике. Функциональные требования остаются в [TECHNICAL_SPEC](TECHNICAL_SPEC.md), согласованное направление — в [UI_REDESIGN_DESIGN](UI_REDESIGN_DESIGN.md).

Текущий художественный статус: автор отверг описанную ниже прежнюю версию из-за дешёвого оформления сцены, декора и UI. Функциональные проверки этой версии остаются историческим фактом, а не художественной приёмкой. После трёх реальных генераций автор выбрал архитектуру «Ночного ателье» и цвета комнат «Светящегося кампуса». Новый проход выполняется по [UI_REDESIGN_V2_PLAN](UI_REDESIGN_V2_PLAN.md); его итоговые проверки и снимки будут записаны после реализации.

## Работающий результат

[Локальное приложение](http://127.0.0.1:5180) использует большую процедурную фабрику, десять зон и семь разных роботов. Основная тема — графитовая с электрическим голубым и оранжевым; светлая версия использует ту же геометрию. Управление, роль и данные раскрываются по запросу, подписи зон — при наведении/фокусе. Escape закрывает сначала подсказку, затем панель; незавершённый ввод сохраняется.

Камера вписывает реальные границы площадки и оборудования. Приближение действительно увеличивает объекты, сброс восстанавливает исходный вид. Геометрия и HTML-якоря используют общую модель камеры. Внешность выбирается через appearance_id, независимо от role/position; неизвестные ресурсы имеют явный fallback в метаданных представления.

Один activePanel исключает перекрытие органов управления. Задержанная загрузка или сохранение не меняют выбранную пользователем панель. Ошибка команды видна над main, включая отказ Start после сворачивания управления. Отсутствие и потеря WebGL сохраняют доступ к HTML-кнопкам.

Worker, платные/реальные LLM-роли, генерация Clinic Demo, Runner, preview и replay UI не подключены. Start сохраняет очередь. Offline-персонажи не изображают работу; неизвестные расходы остаются неизвестными.

## Покрытые сценарии и red → green

- Renderer: отсутствующий Canvas и неверные Three/Fiber импорты воспроизведены до исправления; финальная сцена загружается без renderer errors.
- Камера: crop на 1366/1920/430 и обратное приближение воспроизведены геометрическими тестами. Восемь проверок охватывают углы площадки, увеличение, ограничения и сброс; E2E проверяет настоящие проецируемые кнопки.
- Панели: закрытие/возврат фокуса, сохранение текста, переключение органов управления, позднее сохранение и начальный пустой GET после выбора панели.
- Ошибки: отказ Start при свёрнутом пульте остаётся видимым. Отрицательный HTTP-сценарий не выдаётся за рабочий запуск.
- Подсказки: mouse/focus/blur, удержание наведением и Escape до обработчика панели; таймеры/listeners/ResizeObserver очищаются.
- Ресурсы: шесть проверок наблюдают реальную структуру JSX/Three-геометрии, сохранение role/position/callback, canonical/alias IDs, fallback без мутации данных и прежние материалы семи видов в двух темах.
- Сохранённые сценарии foundation: создание/история/команды/reload/reconnect, поздние списки, 32 PostgreSQL-последовательности snapshot == event projection, HTML без WebGL и потеря установленного контекста.

## Ограничения и следующий шаг

Независимое spec review подтвердило выполнение текущего UI-объёма, включая фактические границы Three-геометрии, семь силуэтов и разделение role/appearance_id. Code quality review закрыл замечания к приветственному открытию и подсказкам. Визуальный reviewer проверил все девять окончательных снимков: type/material/ground/thesis/story/panels/truth соответствуют выбранному миру; материальных визуальных препятствий нет. Единственная коррекция касалась устаревшего DESIGN.md; documenter обновил его и sidecar `.impeccable/design.json` по фактическому коду. В отдельном verdict pass reviewer оценил эту документальную правку как `resolved`, `remaining: clear`, `disposition: ship`; вердикт относится к исправленной документации.

Обычный dev запущен на пользовательской базе codehead: API/UI отвечают HTTP 200. Запрос открытия браузерной панели Codex отправлен, статус queued.

Большой ленивый 3D chunk остаётся предупреждением Vite. Измеренные FPS/память, художественный go/no-go и критерии V01–V09 не заявляются по headless-снимкам. На мобильном первоначальный вид — обзор всей фабрики; подробности доступны через масштаб и HTML-панели.

В консоли остаётся upstream deprecation THREE.Clock из R3F/Three. Сообщения WebGL failure/context loss относятся к намеренным отрицательным тестам; они не скрыты. Устаревший выбор PCFSoftShadowMap заменён поддерживаемым percentage/PCFShadowMap.

Следующая функциональная сессия — worker/lease/fencing/attempts, test provider/trace и содержательные PM → Architect → CTO по ROADMAP. Для платного live должны быть определены провайдер, модель и token/cost бюджет.

Исходное состояние перед редактированием сохранено в `.data/backups/ui-baseline-a6d9c35b`. В рабочей папке нет Git; коммиты/push не выполнялись.
