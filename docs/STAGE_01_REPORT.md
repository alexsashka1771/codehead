## Что проверяют сценарии

Property-тест на реальной БД генерирует 32 последовательности pause/resume/cancel/повторов с seed=20261114. На промежуточных и конечных курсорах он сравнивает полный snapshot с production-функцией projectHistory, читая журнал страницами по три события. ID, зависимости, версии и точность времени сохранены. Браузерные сценарии: создание/Start/история, reload, роли/темы/пауза/отмена, WebGL fallback, 10 зон/7 ролей на 1366/1920/430, reconnect при задержанном usage, поздние GET проектов и запусков после успешной мутации.

## Исправления, подтверждённые red → green

| Воспроизведённая проблема | Исправление |
|---|---|
| Задержанный usage удерживал блокировку синхронизации и мешал reconnect | Поток событий синхронизируется независимо; поздний usage проверяет поколение |
| Drei Html не создавал подпись одной зоны | Собственный DOM-слой с координатами камеры; 10 подписей вместо 9 |
| Поздний GET проектов скрывал только что созданный проект | Версия мутации и согласование списка/выбора |
| Поздний GET истории заменял новый run старым | Версии по проекту, merge по last_event_seq и upsert подтверждённых команд |
| Потомок умершего процесса переживал stop | Job Object с KILL_ON_JOB_CLOSE и барьер до запуска целевого процесса |
| npm ci падал на DLL работающего PostgreSQL | Корректный pg_ctl stop своего кластера перед переустановкой |
| Старт PostgreSQL удерживал stdout и оболочка не завершалась после тестов | Daemon не наследует pipes вызывающего процесса; журнал хранится отдельно |

## Какие требования закрывает основа

A07/A08/A15–A17 проверены в границах текущей платформы. A10 подтверждён для существующей модели состояния; replay UI и данные будущих модулей ещё не реализованы. A11 закрыт по зонам/ролям/выбору/темам, передача артефактов потребует генерации.

Обновлённое ТЗ определяет все дополнения: разделение шаблона и работы ролей, клинические инварианты, CI/live, события/immutable content, uncertain, предложения файлов, бюджеты, Windows/Runner, независимые тесты, trace, API и методику исследований. Формулировки будущих требований не выдаются за работающий код.

## Ограничения и следующий этап

- Worker, AgentRun/ToolRun/Decision, семь реальных LLM-ролей, генерация Clinic Demo, QA/repair, Runner, preview и replay UI ещё впереди.
- Artifact сейчас представлен метаданными; безопасная выдача неизменяемого содержимого и расширение property-теста нужны до генерации файлов.
- Реальных LLM-запросов на этом этапе не выполнялось. До live нужны провайдер, модель и token/cost бюджет; расходы неизвестны.
- Графический chunk: 933.68 kB / 247.58 kB gzip, загружается отдельно. Vite предупреждает о размере; предупреждение не подавлялось. Есть предупреждения совместимости THREE.Clock/PCFSoftShadowMap; сцена работает с текущими версиями.
- Намеренное отключение WebGL в тесте даёт ожидаемое сообщение renderer, после чего работают HTML-контроли.
- FPS, UX-эффективность 3D и польза семи ролей пока не измерены. В ТЗ записаны план, оборудование и допустимость отрицательного результата.
- Локальный PostgreSQL использует учебный loopback trust. Сильная изоляция Runner не реализована.
- Тестовые schemas, отчёты и проверочные окружения сохранены в .data; автоматического удаления данных нет.
- Реквизиты вуза/кафедры/автора/руководителя оставлены для заполнения в [COURSEWORK_DETAILS](COURSEWORK_DETAILS.md).

Следующий конкретный шаг: worker с lease/fencing и восстановлением попыток, затем test provider/trace и первые содержательные роли по [R03/R04/R12](TECHNICAL_SPEC.md). Первый этап не означает завершённую курсовую.
