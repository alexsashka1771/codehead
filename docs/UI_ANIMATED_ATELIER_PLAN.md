# План: живое 3D-ателье для MVP

22 ноября 2026 года. Продолжение выбранного автором направления: архитектура и свет концепта №1, цветовые идентичности комнат концепта №3. Автор дополнительно закрепил: уже для MVP модели должны двигаться, рабочая анимация должна следовать процессу, поле должно вращаться. Спрайты и плоская подмена сцены не допускаются.

**Цель:** рабочее ателье из объёмной геометрии, семь узнаваемых моделей с суставами, вращаемая камера, анимация по серверным состояниям и отдельный явно обозначенный просмотр клипов моделей.

**Архитектура:** Python/контракты/БД и текущий сохранённый процесс не меняются. Слои frontend: серверный snapshot → чистая presentation/motion model → маршруты layout → rigged Asset Registry → Animation Controller. R3F рисует геометрию, HTML остаётся альтернативой управления. Поворот камеры и движение модели обновляют якоря по реальной матрице камеры и текущему положению модели.

**Стек:** React 19, R3F 9, Three.js 0.187, Drei OrbitControls, собственные SkinnedMesh/Bone/Skeleton и клипы AnimationMixer; Vitest и изолированный Playwright. Git отсутствует, коммиты не запрошены.
