# CodeHead — контекст интерфейса

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React 19, TypeScript, Vite, React Three Fiber 9. Приложение работает локально в браузере; источник состояния — Python API и PostgreSQL.

## Пользователь и задача

Автор учебного проекта описывает Clinic Demo, создаёт сохраняемый запуск, изучает очередь, роли и журнал событий. Главный экран объединяет изометрическую фабрику и компактное управление процессом. Полный сценарий доступен через HTML без WebGL.

## Подтверждённые границы первого этапа

Семь ролей, десять логических зон, создание проекта и очереди, выбор сохранённого запуска, пауза, возобновление, отмена. Снимок, история и поток событий поступают с сервера. Worker и LLM ещё не подключены; сцена не изображает работу. Неизвестные показатели использования не заменяются нулём. Security, Research, Meeting и Production отмечены как планируемые.

## Источники требований

Единственный нормативный источник — docs/TECHNICAL_SPEC.md. README.md описывает фактический запуск, IMPLEMENTATION_PLAN.md — текущий этап. Автор выбрал графитовый интерфейс, электрический голубой и оранжевый, с основной ночной темой и вторичной дневной. После критики прежнего декора 22 ноября 2026 года уточнил направление: архитектура и UI сгенерированного «Ночного ателье», цветовое оформление помещений из «Светящегося кампуса». Оба референса и происхождение сохранены в `.impeccable/mocks/approved`. Художественный пилот и критерии диплома проверяются отдельно.

## Выбранное взаимодействие

Фабрика занимает свободное пространство окна. Панели проекта, роли и данных раскрываются по запросу; одновременно открыта одна. Закрытие сохраняет незавершённый ввод и возвращает фокус. Подписи зон появляются при наведении/фокусе; подсказку можно удержать наведением и закрыть Escape. Ошибки команд и соединения видны вне скрытых панелей. Источник данных остаётся серверным.
